# BS Exchange

- `api/` — NestJS backend (sports & cricket fancy via PulseScore, InOut casino, Teen Patti, Andar Bahar, Sic Bo, Wheel, agents, wallet). `npm run build` → `api/dist`, `npm start`.
- `web/` — built player site (`web/`) and admin panel (`web/admin/`), served from public_html.

Secrets go in `api/.env` (see `api/.env.example`), never in the repo.
